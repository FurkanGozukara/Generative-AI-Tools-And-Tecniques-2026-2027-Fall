ComfyUI manual-installation update

Open the existing ComfyUI folder in File Explorer. Enter cmd in its address bar.

venv\Scripts\activate
where python
git pull --ff-only --no-stat
python -m pip install -r requirements.txt

After activation, the prompt starts with (venv), identifying the active virtual environment in that window. The first where python result must point into this installation's venv. Run the requirements command with normal output so the complete installation logs remain visible. Wait for the prompt to return, restart the server, then refresh its browser page.
