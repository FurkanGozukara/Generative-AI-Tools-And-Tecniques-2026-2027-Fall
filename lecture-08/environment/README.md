# Recorded environment

These files were written by the commands shown in Lecture 8 and are copied unchanged:

- [Lecture08_core_commit.txt](Lecture08_core_commit.txt): the ComfyUI Git commit.
- [Lecture08_requirements_lock.txt](Lecture08_requirements_lock.txt): the installed packages reported by `pip freeze`.
- [L08_snapshot.json](L08_snapshot.json): the Manager snapshot, including registered custom-node versions and package references.

Use them to compare a problem against the recorded setup. They describe installed state; they do not contain software, models or input assets. Recreating GPU packages also depends on your Python, platform and available package builds. The [command guide](../commands.md) shows how the lecture saved these records and inspected the restore command's options.
