| File | Example |
|---|---|

[queue_outcomes.json](queue_outcomes.json) preserves the recorded queue summary: two completed jobs and a final job cancelled while waiting. There is no third result image because that job was removed before it ran. The filenames in that summary are the original server filenames; the copies here use the shorter names listed above.

The PNGs retain their workflow metadata. Importing an image's metadata still requires matching installed nodes, models and input files. [SHA256SUMS.txt](../SHA256SUMS.txt) records the companion copies' hashes.
